Required first-run step for an existing database:
1. Back up MongoDB.
2. In backend, run `npm run migrate:tickets` only if the existing database has not already had the ticket-code migration applied.
3. Start backend and frontend, then follow docs/QA-SECURITY-CHECKLIST.md.
4. `npm run seed:demo` is content-only and requires an existing admin; it does not touch User records. Do not run the separate `npm run seed` command unless you intentionally want its admin-account operation.
