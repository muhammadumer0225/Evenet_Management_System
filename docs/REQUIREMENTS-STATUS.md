## Required first-run database step

For an existing database, take a backup first. Run the migration from `backend` only if it has not already been applied:

```bash
npm run migrate:tickets
```

The migration fills missing ticket codes, backfills legacy session-registration `type` values to `register`, and recalculates `Expo.registeredCount`.

## Acceptance decision

The project is **not yet live-acceptance certified**. Source implementation and unit tests have improved, but local MongoDB/SMTP/AI setup, browser interaction, Socket.IO multi-user tests and the remaining booth/feedback/accessibility/performance checks must be completed before submission or production deployment. Android APK packaging is outside the current web-project scope.
